<h2 align="center">ℹ️ How this distribution works</h2>

- Official FULL IPA is always preferred.
- Official IPA is verified before publishing.
- Official IPA bytes are mirrored unchanged.
- If no usable official IPA exists, the fallback build activates.
- Fallback builds use the exact matching official Nuvio source.
- SideStore source URL remains the same in both cases.
